Interactive Explorer

Use the controls below to filter and compare different training runs in real-time.

Code 
viewof selected_exp = Inputs.select(
  [...new Set(research_data.exp_name)], 
  {label: "Experiment", value: research_data.exp_name[0]}
)

viewof selected_dim = Inputs.select(
  [null, ...new Set(research_data.adapter_dim)], 
  {label: "Adapter Dim", format: d => d === null ? "All" : d}
)

viewof selected_lr = Inputs.select(
  [null, ...new Set(research_data.learning_rate)], 
  {label: "Learning Rate", format: d => d === null ? "All" : d}
)

viewof min_acc = Inputs.range(
  [0, 1], 
  {label: "Min Accuracy", step: 0.01, value: 0.5}
)

Training Dynamics

Code 
filtered_data = {
  const data = transpose(research_data);
  return data.filter(d => 
    d.exp_name === selected_exp && 
    (selected_dim === null || d.adapter_dim === selected_dim) &&
    (selected_lr === null || d.learning_rate === selected_lr) &&
    d.accuracy >= min_acc
  );
}

// Interactive Plot using Observable Plot
Plot.plot({
  grid: true,
  color: {legend: true},
  y: {label: "Value"},
  marks: [
    Plot.line(filtered_data, {
      x: "epoch", 
      y: "train_loss", 
      stroke: "full_name", 
      strokeDasharray: "4,4",
      tip: true
    }),
    Plot.line(filtered_data, {
      x: "epoch", 
      y: "val_loss", 
      stroke: "full_name",
      tip: true
    }),
    Plot.dot(filtered_data, {
      x: "epoch", 
      y: "val_loss", 
      fill: "full_name"
    })
  ]
})

🚀 Scientific Insights

  • Real-time Interactivity: Observable JS allows us to query the aggregated Parquet results instantly without server-side re-renders.
  • PEFT Monitoring: High-granularity step logging (integrated in trainer.py) reveals exactly where models begin to plateau.
  • Architectural Trade-offs: Compare how different adapter_dim values impact convergence speed vs. final accuracy across the sidebar sections.
